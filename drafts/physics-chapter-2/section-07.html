২.৭ · সমত্বরণে গতির ৪টি মৌলিক সমীকরণ

কোনো বস্তু যখন নির্দিষ্ট দিকে **ধ্রুব ত্বরণে ($a$)** সরলরেখা বরাবর গতিশীল থাকে, তখন আদিবেগ ($u$), শেষ বেগ ($v$), ত্বরণ ($a$), সময় ($t$) এবং সরণ ($s$)—এই পাঁচটি রাশির পারস্পরিক সম্পর্কের সমীকরণগুলো হলো গতির সমীকরণ।

১ম সমীকরণ ($s$ অনুপস্থিত) $$v = u + at$$
২য় সমীকরণ ($a$ অনুপস্থিত) $$s = \frac{u + v}{2} \times t$$
৩য় সমীকরণ ($v$ অনুপস্থিত) $$s = ut + \frac{1}{2}at^2$$
৪র্থ সমীকরণ ($t$ অনুপস্থিত) $$v^2 = u^2 + 2as$$

সমীকরণগুলোর সহজ প্রতিপাদন (Derivations)

  1. ১ম সমীকরণ ($v = u + at$):
    ত্বরণের সংজ্ঞা হতে আমরা জানি, $a = \frac{v - u}{t} \implies at = v - u \implies v = u + at$।
  2. ২য় সমীকরণ ($s = \frac{u+v}{2}t$):
    সুষম ত্বরণে বস্তুর গড় বেগ হলো আদি ও শেষ বেগের সাধারণ গড়, $\bar{v} = \frac{u + v}{2}$। আবার আমরা জানি মোট সরণ $s = \bar{v} \times t$। সুতরাং $s = \frac{u + v}{2}t$।
  3. ৩য় সমীকরণ ($s = ut + \frac{1}{2}at^2$):
    ২য় সমীকরণে $v$-এর মান ($u + at$) বসালে পাই:
    $$s = \frac{u + (u + at)}{2} \times t = \frac{2u + at}{2} \times t = \left(u + \frac{1}{2}at\right)t = ut + \frac{1}{2}at^2$$
  4. ৪র্থ সমীকরণ ($v^2 = u^2 + 2as$):
    ১ম সমীকরণ থেকে সময় $t = \frac{v - u}{a}$। এই মানটি ২য় সমীকরণে বসালে পাই:
    $$s = \left(\frac{v + u}{2}\right) \left(\frac{v - u}{a}\right) = \frac{v^2 - u^2}{2a} \implies 2as = v^2 - u^2 \implies v^2 = u^2 + 2as$$

🧭 কোন সমীকরণ কখন ব্যবহার করবে? (Magic Selection Table)

প্রশ্নে যে রাশিটি দেওয়া নেই ও চাওয়া হয়নি যে সমীকরণটি বেছে নেবে
দূরত্ব বা সরণ ($s$) অনুপস্থিত $v = u + at$
ত্বরণ ($a$) অনুপস্থিত $s = \frac{u + v}{2}t$
শেষ বেগ ($v$) অনুপস্থিত $s = ut + \frac{1}{2}at^2$
সময় ($t$) অনুপস্থিত $v^2 = u^2 + 2as$

📝 পাঠ্যবইয়ের স্ট্যান্ডার্ড গাণিতিক সমস্যা

একটি স্থির দাঁড়িয়ে থাকা গাড়ি $2\text{ m/s}^2$ সমত্বরণে চলতে শুরু করল। $5\text{ s}$ পর গাড়িটির শেষ বেগ এবং অতিক্রান্ত দূরত্ব কত হবে?
প্রদত্ত তথ্য:
স্থির অবস্থা থেকে শুরু করায় আদিবেগ $u = 0\text{ m/s}$
ত্বরণ $a = 2\text{ m/s}^2$
সময় $t = 5\text{ s}$

১. শেষ বেগ ($v$) নির্ণয়:
$$v = u + at = 0 + (2 \times 5) = 10\text{ m/s}$$
২. অতিক্রান্ত দূরত্ব ($s$) নির্ণয়:
$$s = ut + \frac{1}{2}at^2 = (0 \times 5) + \frac{1}{2} \times 2 \times (5)^2 = 0 + 25 = 25\text{ m}$$
উত্তর: শেষ বেগ $10\text{ m/s}$ এবং অতিক্রান্ত দূরত্ব $25\text{ m}$।

🧠 মনে রাখার টেকনিক: $u = 0$ হলে রূপ

বস্তু যদি স্থির অবস্থান থেকে শুরু করে ($u = 0$), তবে সূত্রগুলো নিমেষেই ছোট হয়ে যায়:
• $v = at$
• $s = \frac{1}{2}at^2 \implies s \propto t^2$ (দূরত্ব সময়ের বর্গের সমানুপাতিক!)
• $v^2 = 2as \implies v \propto \sqrt{s}$

প্রশ্ন: একটি গাড়ির আদিবেগ $10\text{ m/s}$, শেষ বেগ $30\text{ m/s}$ এবং সরণ $100\text{ m}$ হলে ত্বরণ কত?

উত্তর: এখানে সময় $t$ নেই। তাই ৪র্থ সমীকরণ ব্যবহার করব:
$v^2 = u^2 + 2as \implies (30)^2 = (10)^2 + 2a(100) \implies 900 = 100 + 200a \implies 200a = 800 \implies a = 4\text{ m/s}^2$।
